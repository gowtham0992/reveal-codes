Hook payload fixtures for the provenance recorder. Each file is `{"meta": {...}, "payload": {...}}` for one event or `{"meta": {...}, "events": [{"payload": {...}}, ...]}` for an ordered sequence. `meta.how` says how the payload was captured. Every prompt, session id, path and text value is a placeholder (`<prompt placeholder>`, `<session A>` to `<session F>`, `<workspace>`, `<absolute path>`, `<text placeholder>`, `<response placeholder>`); a distinct session placeholder stands for one captured session. `hook_event_name` holds the trigger name; the probe recorded field types only, so these names come from the hook trigger list, not from a captured string.

- `ide/user-prompt-submit.json`, `ide/stop.json`, `ide/pre-tool-use-fs-write.json`, `ide/post-tool-use-fs-write.json`: IDE chat tab A (session A), captured 2026-11-18 with a plain prompt and a file-write prompt. `ide/user-prompt-submit-tab-b.json` and `ide/stop-tab-b.json`: a second IDE chat tab (session B), 2026-11-18. `ide/extra-session.json`: one more IDE chat session (session E), 2026-11-18.
- `ide/pre-task-exec.json`, `ide/post-task-exec.json`, `ide/specs-panel-session.json`: a task started from the Specs panel on a scratch spec (session C), 2026-11-18. The session is its own session and has no UserPromptSubmit.
- `ide/orchestrator-session.json`: the orchestrator spec chat (session D), 2026-11-18: Stop with no UserPromptSubmit, plus PreTaskExec and PostTaskExec for one task.
- `cli/user-prompt-submit.json`, `cli/stop.json`, `cli/pre-tool-use-fs-write.json`, `cli/post-tool-use-fs-write.json`, `cli/turn-without-task-events.json`: the CLI (session F), 2026-11-18, with plain and file-write prompts. Every `fs_write` path is absolute on both surfaces.
- Not captured: CLI PreTaskExec and PostTaskExec. The CLI fired none when asked in chat to run a spec task, so there is no CLI task fixture and the CLI hook order could not be measured.
